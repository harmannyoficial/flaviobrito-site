# 🧠 Plataforma para Psicologia

Um projeto desenvolvido com foco em oferecer uma experiência moderna, acolhedora e acessível para profissionais da psicologia e seus pacientes.

A aplicação busca unir tecnologia e bem-estar, criando um ambiente digital intuitivo, com design responsivo e adaptável para diferentes dispositivos.

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, garantindo uma boa experiência tanto em desktops quanto em dispositivos móveis.

✔️ Layout adaptável para diferentes tamanhos de tela  
✔️ Navegação otimizada para celular  
✔️ Estrutura pensada para usabilidade mobile  

## 💡 Sobre o projeto

Este projeto foi criado com o objetivo de praticar desenvolvimento web, ao mesmo tempo em que entrega uma interface moderna voltada para a área da saúde mental.

O foco principal está em:
- Interface limpa e acolhedora  
- Experiência centrada no usuário  
- Design responsivo  
- Navegação simples e intuitiva
